# Booking Manager

> Booking Manager - A web app that helps vacation rental hosts to organize their accomodations' reservations. using HTML

## Overview

Booking Manager is a powerful web app designed to help Vacation Rental Hosts to hold a personal record of their reservations and to manage out-of-the-platform bookings easily. Built with HTML, it combines modern development practices with user-centric design.

## Key Features

- Booking Calendar, Dynamic Pricing,  Reservation Catalog Print Feature

## Tech Stack

- HTML

## Disclaimer:
- As of now, the data that is inserted in the web interface is saved in the local storage of your browser. Deleting your browser's cache, will delete the data as well.
