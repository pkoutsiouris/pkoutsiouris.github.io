Πολιτική Απορρήτου

Πώς διαχειριζόμαστε τα δεδομένα σας

Τοπική Αποθήκευση (Local Storage): Δεν συλλέγουμε ούτε αποθηκεύουμε τα προσωπικά ή οικονομικά δεδομένα σας στους διακομιστές (servers) μας. Όλες οι πληροφορίες κρατήσεων αποθηκεύονται αποκλειστικά στη συσκευή σας μέσω της τοπικής μνήμης του προγράμματος περιήγησής σας (localStorage).

⚠️ Προσοχή: Τα δεδομένα που αποθηκεύονται τοπικά δεν είναι κρυπτογραφημένα από την εφαρμογή. Σας συμβουλεύουμε να αποφεύγετε τη χρήση αυτής της εφαρμογής σε δημόσιους ή κοινόχρηστους υπολογιστές.

Υπηρεσίες Τρίτων: Για τη σωστή εμφάνιση και λειτουργία της εφαρμογής, φορτώνονται απαραίτητοι τεχνικοί πόροι (όπως γραμματοσειρές και σενάρια σχεδίασης) από αξιόπιστα εξωτερικά δίκτυα (Google Fonts, JSDelivr). Αυτές οι υπηρεσίες ενδέχεται να έχουν πρόσβαση στη διεύθυνση IP σας προκειμένου να σας παραδώσουν τα απαραίτητα αρχεία.
